## Skill-tár és GitHub repos (haladóknak)

Ezek a Claude Code skill-keretek és GitHub repók, amik a 6. modul témájához (copy + landing page) kapcsolódnak — ha mélyebbre akarsz menni a Claude Code automatizációival.

- 🔗 **copy-engine skills** — saját skill-csomag, ami a Schwartz-féle awareness-szintek és a Caples-féle headline-formulák logikájával 10 headline-variációt generál egy validált fájdalompontból (a `prompts.md` 6.1 promptjának kibővítése)
- 🔗 **landing-builder skill** — a copy + design párhuzamos generálása: a webfactory taste-engine bírálatát is meghívja, mielőtt a végleges landing.html elkészül
- 📄 **taste-skill** — https://github.com/leonxlnx/taste-skill (anti-AI-slop ízlésbírálat: a Claude generált landing.html-t automatikusan minőségi-szempontból elemzi és újratervezi, ha tucsi-tucsi lenne. Hasznos, ha a copy mellett a vizuális minőséget is szigorúan akarod tartani.)
- 📄 **Remotion AI Skills** — https://www.remotion.dev/docs/ai/skills és https://github.com/remotion-dev/skills (animált motion graphics-elemek a landing-re — pl. animált CTA, kinetic headline, scroll-vezérelt mozgó-elem React-tel és Remotion-nel programozva. A 20. bónusz videókurzus-építéséhez is használható.)
