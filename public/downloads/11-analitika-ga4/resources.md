# 11. modul — Hasznos linkek

## Eszközök

- **Google Analytics 4** — https://analytics.google.com (ingyenes, a Workspace-fiókoddal regisztrálsz)
- **gtag.js dokumentáció** — https://developers.google.com/tag-platform/gtagjs (a hivatalos snippet és event API)
- **Google Tag Assistant** — https://tagassistant.google.com (Chrome extension, hogy ellenőrizd, mennek-e az események)
- **GA4 DebugView** — analytics.google.com → Configure → DebugView (real-time esemény-tesztelés)
- **VS Code + Claude Code** — a JavaScript trackerek megírásához

## Magyar referenciák
