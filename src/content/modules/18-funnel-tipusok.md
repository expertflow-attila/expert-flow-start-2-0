# 5. modul — Funnel típusok

## Module summary

A 4. modul az egyes oldalakkal foglalkozott. Az 5. modul az oldalak ÖSSZEKAPCSOLÁSÁVAL — a teljes utazással, amit egy érdeklődő bejár a webhelyedtől a fizetős ügyfélig. 4 funnel-típust mutatok be, mindegyikhez egy end-to-end leírás, email-sablonok, és Apps Script vagy automatizációs lépések. Ezek nem egymást kizáró opciók — egyszerre több funnel is futhat a webhelyeden, különböző forgalmakra.

## Almodulok (Skool sub-lessons)

1. **Konzultációs funnel** — landing → Cal.com → consult → ajánlat (kézi vagy automatikus)
2. **Lead magnet funnel** — regisztráció → PDF → 5 email welcome → soft CTA
3. **Online előadás funnel** — regisztráció → emlékeztetők → előadás → utánkövetés
4. **Discovery → ajánlat → fizetés** — discovery call → ajánlat-PDF → Stripe Payment Link

## Key highlights

- A funnel nem mágia — 3-5 lépésből álló, automatizált utazás. Minden lépés egy konkrét cselekvés a látogató részéről.
- A **konzultációs funnel** a legtöbbet hozza kezdetben — alacsony konverziós küszöb (csak időt foglal), magas érték.
- A **lead magnet funnel** a hosszú távú email-lista építője — később ezekre küldesz szolgáltatás-ajánlatot.
- A **webinar funnel** akkor erős, ha élőben tudsz építeni — magyar piacon ma is működik.
- A **discovery → fizetés funnel** a már bevált, magas árú szolgáltatásokhoz — itt kell a legtöbb bizalom.
